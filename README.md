# Reproducibility package — "Hard Structural Vetoes Under Unseen Trial Shift: An Empirical Study of LLM-Based Clinical Trial Matching"

INDICON 2026, Paper ID 5232. Anonymous code-review release.

This package reproduces the paper's reported statistics for non-small-cell lung cancer (NSCLC)
clinical-trial eligibility matching, comparing a hard-veto neuro-symbolic hybrid against LLM-only
baselines and an exploratory advisory policy. The model-serving code (prompts, structural verifier,
retrieval, patient generation) is included **for transparency**; the reported **numbers reproduce
from frozen per-pair predictions with no API, database, or model calls**.

## Quickstart
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cd analysis
python exp9_significance.py
python exp10_revision_fixes.py
python exp11_robustness.py
# outputs land in ../results and match the included JSONs
```

## Included vs excluded
**Included:** the exact prompts; the structural/retrieval/generation modules (transparency); the
frozen synthetic dataset and split report; the frozen test-set predictions for every reported
condition; the cache-only analysis scripts; and the precomputed result JSONs.

**Excluded (by design):**
- **Secrets** — no API keys, tokens, or credential files (e.g. no `groq_keys.txt`, no `.env`). All
  credentials in the code read from environment variables.
- **Provisional / unlabeled data** — the development-expansion set and its provisional labels
  (`internal_key_expansion.csv`, `annotation_expansion.csv`, `patients_expansion.jsonl`).
- **Raw annotator files** — not part of this release.
- Superseded `old_data/`, `old_results/`, and `venv/`, `__pycache__/`.

## Notes
- LLM serving is non-deterministic even at temperature 0 (two temperature-0 passes over the 270
  test pairs agreed on 264/270), so live regeneration is not bit-identical. The frozen predictions
  are provided so the statistics reproduce **exactly**.
- Patients are synthetic; trial criteria come from the public TREC 2022 Clinical Trials corpus.
